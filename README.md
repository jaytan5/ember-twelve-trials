# 小泥团，出击！ · 卡牌游戏 Demo

Godot 4.7.2 项目，12场战斗，第3、6、9、12关为Boss。

## 启动

用 Godot 导入 `project.godot`，或双击 `启动游戏.cmd`。本机引擎位于工程上一级。
启动脚本会先自动导入资源，再打开游戏；首次下载或更新后请等待导入完成。导入失败时窗口会保留错误信息，日志位于 `.godot/startup-import-console.log`。
入口为 `Game/Scenes/Main.tscn`。

## 界面与冒险流程

默认窗口 1280×720，逻辑画布 1600×900（16:9），窗口缩放保持比例；其他比例的屏幕留边显示。

游戏名称为「小泥团，出击！」。为兼容已有进度，继续使用原有本机存档目录，改名不会清空存档或音量设置。
游戏内使用[星芒小剑透明指针](Game/Assets/UI/Cursors/星芒小剑-透明.png)，资源和制作记录见[指针素材说明](Game/Assets/UI/Cursors/指针素材说明.md)。
开始菜单和难度按钮没有悬停文字提示；路线界面移除辅助介绍、推荐和页脚文字，保留路线、难度与确认操作。设置页底部保留字体版权标注，并说明美术与音乐资产由 AI 生成。

- 启动时仅显示循环背景、上方居中的「小泥团出击」透明 Logo 和中下方白字「按任意键开始游戏」，同步播放背景音乐。按键、鼠标点击、触摸或手柄按键后显示「开始新冒险」「继续冒险」「设置」；首次操作不穿透菜单，视频和音乐不中断。返回主界面直接显示菜单。Logo 资源见 [标题素材说明](Game/Assets/UI/Titles/标题素材说明.md)。
- 开始界面以无音轨 OGV 视频「开篇循环背景动画」为循环背景，菜单位于右侧半透明区域；离开开始界面停止视频，返回后重新播放。设置弹窗与界面重绘不会重启视频，详见 [视频说明](Game/Assets/Videos/视频说明.md)。
- 新冒险先选择路线与难度，再进入关卡地图；有旧存档时确认后才覆盖。
- 继续冒险先确认存档路线，路线与难度锁定；确认后进入地图，保留原卡组、生命和当前战斗/奖励/补给进度。
- 地图分为青苔边境、失落铁城、血砂荒原、余烬王座，每区两场普通战斗和一场 Boss 战。完成战后补给后在地图解锁下一关。
- 右上角设置菜单包含关卡地图、卡组、图鉴、玩法、保存、声音与显示、返回主界面和返回。Esc 打开/关闭菜单。
- 左下为带头像的个人属性面板，中间为可横向滚动的手牌，右侧竖排牌堆按钮，右下结束回合。
- 个人状态栏只显示已有状态与已排定的下回合效果，零值状态隐藏。「汲取可恢复」仅在出战卡组含汲取或汲取+且有可恢复伤势时显示，备用卡库不计入。卡组管理与备用卡库以卡名显示，悬停查看完整卡牌，支持拖动换牌。
- 战斗逐段播放框体震动和快速血条动画，再保存并展示结果；多段攻击、毒素、反伤、吸血和药水按实际顺序播放。主角单次实际生命损失按小于15、15–40、大于40分为小/中/大震动，敌人为小于20、20–50、大于50。护甲完全抵挡时只闪光，治疗播放回血动画。动画期间锁定操作，最后一击结束后才展示胜利或失败。
- 基础设置支持总音量、音效音量、试听和全屏；音量控制已接入按钮、选敌与出牌音效，偏好独立保存在 user://settings.cfg。
- 开始界面与路线选择页循环播放《The World-Saving Heroic Quest》，进入冒险后停止，返回主界面时从头播放；刷新界面与打开设置不会重启音乐。音乐受「总音量」控制，资源与接入说明见 [音频说明](Game/Assets/Audio/音频说明.md)。

## 遗物、难度与字体

- 进阶宝石：狂刃开战 +2 力量；铁壁开战 +4 护甲；蚀毒每场首次施毒额外 +3 层，与初始遗物叠加。
- 连击齿轮：每回合第 2、4、6 张成功打出的卡牌结算后，对随机存活敌人造成 6 点普通伤害；最多 3 次，不吃力量加成。
- 逆命护符：每场限一次，玩家回合开始时生命严格低于 50%，额外抽 2 张牌并获得 3 能量；遵守 10 张手牌上限。
- 四档为轻松、标准、勇者、传奇。前三档保留原有预告和敌人数值规则，战败可重开当前小关；传奇沿用勇者数值，但战败只能从第一关重新开始。
- 小关重试恢复开战时完整状态及随机数状态，重试本身不发放奖励，读档后也可重试。旧存档没有开战快照时，保留当前拥有的资源并满血重建本关；进入下一关后即使用完整快照。
- 标题、卡名与按钮使用阿里妈妈方圆体，说明、状态与记录使用 MiSans。字体随游戏打包，来源与版权见 [字体说明](Game/Assets/Fonts/字体说明.md)。

## 当前回合规则

- 初始17张：12张通用牌＋5张路线牌。
- 首回合抽5张，之后每回合保留手牌并抽2张，最多10张；满手牌后停止抽取，牌留在牌库。
- 普通牌使用后进入弃牌堆；抽牌堆空时洗入弃牌堆。能力牌和急救使用后本场移出，下场恢复。
- 每回合默认3能量；厚积薄发可消耗全部当前能量，在下一回合额外获得对应能量。
- 点击目标、点击卡牌，数字1–9、0出牌，左右方向键选敌，空格结束回合。
- 出战卡组15–30张，战斗外可以在出战与备用卡库之间移动卡牌。

完整卡牌、升级效果见 [卡牌与路线说明](卡牌与路线说明.md)，关卡和怪物数值见 [完整设定](游戏完整设定-卡牌与怪物.md)。

## 模块和数据

见 [工程结构说明](Game/ARCHITECTURE.md)。卡牌、怪物、Boss、关卡、遗物和奖励均使用独立 `.tres` Resource。调数值直接编辑对应资源；增加全新机制时扩展效果结算器。

旧 `scripts/` 和 `main.tscn` 作为兼容入口保留，实际实现位于 `Game/`。

## 存档

新版为v8，兼容v1–v7。药水携带上限为2瓶，旧存档与重试快照同步限制；永久删牌功能已移除，仍可免费移入备用卡库。虚弱与易伤改为基础1回合、升级2回合，旧持续状态迁为剩余1回合。已删除卡牌迁移为：应急包扎→卸力、振作→厚积薄发、佯攻→识破、未雨绸缪→金钟罩；重复副本与升级保留。旧存档超过10张的手牌移回抽牌堆，不丢失。旧存档出战不足15张时，先从备用卡库补齐；仍不足时免费补入斩击/防守，原有卡牌与升级保留，战斗中新增牌进入抽牌堆。旧狂怒与嗜战数值移除。既有卡组不会被强制换成新初始牌；开始新冒险即可体验17张起始配置。

测试使用工程内 `.test_profile`，不会覆盖玩家存档。

## 验证

在项目目录执行 `powershell -ExecutionPolicy Bypass -File tests/run_checks.ps1`。
添加 `-Rendered` 可运行实际渲染截图检查。日志和截图存于 `test-results/`。
测试覆盖卡牌升级、保留手牌、10张上限、冰冻、金钟罩、X费用、消耗牌、迁移与随机状态，以及三路线自动对局；界面检查覆盖主界面→路线→地图→战斗、锁定路线续玩、地图往返不重置战斗、音量持久化、十张手牌快捷键及窗口比例。自动胜率仅用于回归，不代表玩家胜率。
