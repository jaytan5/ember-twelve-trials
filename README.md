# 余烬十二关 · 卡牌游戏 Demo

这是一个可以从选路线一直玩到第 12 关结算的 Godot 4 游戏原型。当前使用文字、色块和程序绘制的敌人符号，方便先验证玩法，后续再替换美术。

## 怎么开始

在 `G:\godot\余烬十二关` 中双击 **启动游戏.cmd** 即可游玩，无需安装额外依赖。工程、说明和测试文件全部集中在这个文件夹内；Godot 引擎作为共用工具保留在上一级 `G:\godot`，启动器会自动调用它。

若要修改工程，双击 **打开编辑器.cmd**，然后按 **F6/F5** 运行主场景/项目。也可以用 Godot 导入 `project.godot`。

建议从「铁壁」路线开始。首页点选路线后，点击「开始新冒险」。右上角「玩法」随时可以查看完整规则。

## 难度选择

开始新冒险前，在路线卡片下方选择「简单／中等／困难」。难度整局固定，并随存档保存；修改首页选择不会改变正在继续的那一局。

| 难度 | 行动预告 | 敌人数值 |
| --- | --- | --- |
| 简单 | 显示下一次单次攻击或连击的伤害、次数与总伤害，以及防御、蓄力动作 | 基础数值 |
| 中等（普通） | 隐藏下一步行动和伤害，统一显示「行动未知」 | 与简单相同 |
| 困难 | 同中等，不显示行动预告 | 生命提高 35%；攻击每段伤害、防御值、蓄力增加的力量提高 25%，均向上取整 |

困难倍率适用于所有普通敌人和 Boss，不改变行动顺序与连击次数。已获得的护甲、毒素、力量等当前状态仍然可见；战斗记录显示已经发生的行动，不提前揭示下一步。简单模式的攻击预告计入敌人力量和虚弱，实际生命损失还受玩家护甲影响。

旧存档默认按「简单」继续，保留原有预告与当前战斗数值；读取存档不会重复叠加困难倍率。

## 已实现的玩法

| 模块 | 内容 |
| --- | --- |
| 关卡 | 12 场依次推进的战斗；第 3、6、9、12 关为 Boss |
| 蚀毒 | 叠毒持续伤害 / 消耗毒层引爆；淬毒、毒素回收配合 |
| 铁壁 | 护甲转伤害 / 荆棘反伤；全体冲撞与反击风暴 |
| 狂刃 | 力量多段攻击 / 狂怒爆发；嗜战积攒、怒斩消耗 |
| 卡牌 | 46 种基础卡及对应升级版：通用 16 种，每路线 10 种；初始 11 张牌 |
| 卡组管理 | 出战 5–30 张，备用卡库保留多余卡；战斗外支持拖动与点击换牌 |
| 图鉴 | 菜单及游戏右上角可查看全部卡牌，比较基础版与升级版 |
| 战斗 | 怪物上方、玩家下方；选定目标、固定行动循环；行动预告随难度显示或隐藏 |
| 难度 | 简单 / 中等 / 困难；新局选择、整局固定、存档保留 |
| 牌堆 | 抽牌、弃牌、洗牌、已激活能力区、手牌上限 10 |
| 战利品 | 普通关 30 金币及选牌；Boss 80 金币、回血 15、升级牌及遗物选择 |
| 营火 | 免费休息或永久升级一张牌，二选一 |
| 商店 | 买牌、治疗、补充药水、移除卡牌 |
| 遗物 | 3 件路线初始遗物、8 件可选 Boss 遗物，效果自动生效 |
| 结局 | 战败重开；第 12 关胜利获得余烬王冠并展示本局统计 |
| 存档 | 每次有效操作自动保存；返回菜单或关闭窗口后可继续 |

第 12 关结束直接显示通关结算，前 3 位 Boss 的升级卡与遗物在选择后用于后续关卡。

完整卡牌数值与两套路线玩法见同目录 **[卡牌与路线说明.md](卡牌与路线说明.md)**。

## 调整卡组

战后选牌、选择遗物和营火阶段，点击右上角「卡组」进入双栏管理。左侧为出战卡组，右侧为备用卡库，将卡牌拖到另一侧即可移动，也可以点击卡牌后选择移入。移动不会删除卡牌，不花金币，升级状态保留。

出战最多 30 张、至少 5 张，不要求必须凑满 30 张。满 30 张后，新获得的奖励卡和商店卡自动进入备用卡库，并打开管理界面；先拖出旧卡，再拖入新卡。仅出战卡进入下一关的抽牌堆，备用卡不参与战斗。战斗与结算期间卡组模块为只读。

旧版存档会自动补全新状态和备用卡库，超过 30 张的部分转入备用，保留所有卡牌。不改变正在进行的战斗抽牌堆，下场开始按新的出战卡组组牌。

## 操作

- 鼠标点击上方敌人：选择攻击目标。
- 点击手牌或按数字 **1–9**：立即打出对应手牌。灰色手牌表示能量不足。
- **← / →**：切换存活敌人。
- **空格**：结束回合。
- 药水按钮：恢复 20 生命，不消耗能量；最多携带 3 瓶。
- 抽牌堆、弃牌堆、已激活能力区按钮：查看相应卡牌。抽牌堆按名称显示，不透露顺序。
- 顶部关卡按钮：查看关卡信息，不能跳关。
- **Esc**：关闭当前说明或选择窗口。
- 手牌较多时，可以在手牌区横向滚动。

## 关键规则

每回合默认 3 能量、抽 5 张牌。回合结束时弃掉剩余手牌，未用能量不累计。抽牌堆为空时，将弃牌堆洗回。

护甲抵挡普通伤害，在己方下个回合开始时清空。「固守」本场每回合保留剩余护甲至上限，多张取最高上限；遗物提供的回合护甲在清空后获得。敌方护甲在该敌人行动开始时清空。

毒素在该敌人行动前生效，造成等于层数的伤害，无视护甲，然后减少 1 层。毒死的敌人不会行动。力量增加每段攻击的伤害；易伤使普通伤害增加 50%（向上取整），虚弱使攻击降低 25%（向下取整）。这两个状态在敌方行动后减少 1 回合。

反伤在每次敌方攻击命中时触发，即使护甲完全挡住伤害；反伤击杀后会中止剩余多段攻击。只有能力牌生效后移入「已激活」，下一关恢复；攻击和技能均可循环使用。

营火休息恢复最大生命的 25%（向上取整）。免费休息和锻造只可选择一种；使用营火后仍能购买商店服务。商店买牌 45 金币、治疗 30 金币（恢复 24）、药水 25 金币、删牌 40 金币；治疗和删牌每关限一次，永久卡组至少保留 5 张。

## 存档

正常启动后的存档位于：

```text
%APPDATA%\Godot\app_userdata\余烬十二关 · 卡牌 Demo\run_save.json
```

只有一个存档槽；开始新冒险会提示替换上一局。关闭游戏后可复制该文件备份。通关或战败结算也会保存。测试使用单独的 `.test_profile` 目录，不覆盖玩家存档。

## 后续从哪里修改

| 文件 | 用途 |
| --- | --- |
| `scripts/data.gd` | 卡牌、升级规则、三条路线、遗物、12 关敌人与行动模式；调整数值优先改这里 |

| `scripts/main.gd` | 菜单、战斗界面、卡牌、商店、弹窗和输入 |
| `scripts/deck_manager.gd` | 出战/备用双栏卡组管理、原生拖放、点击移动及数量限制提示 |
| `scripts/sigil.gd` | 当前敌人的几何占位图；替换美术时可改成贴图组件 |
| `main.tscn` | 游戏入口场景 |
| `project.godot` | 窗口、渲染及工程配置 |
| `tests/test_rules.gd` | 规则断言和三路线自动对局 |
| `tests/ui_smoke.gd` | 各页面渲染、边界检查和真实鼠标/键盘输入检查 |

角色原画、卡面、背景等可以接入 `main.gd` 的 `enemy_view()`、`card_view()` 及 `build_battle()`；无需改变战斗数据逻辑。现阶段没有音效、联网或局外养成，数值以快速体验完整流程为目标，仍属于初版平衡。

## 验证

在工程目录运行规则测试：

```powershell
..\Godot_v4.7.2-stable_win64_console.exe --headless --path . --script res://tests/test_rules.gd --log-file .\test-results\rules.log
```

界面测试会模拟出牌并写测试存档，须使用独立的进程环境。请在单独 PowerShell 窗口中运行以下命令，结束后关闭该窗口：

```powershell
New-Item -ItemType Directory -Force .test_profile\Roaming,.test_profile\Local | Out-Null
$env:APPDATA = Join-Path (Get-Location).Path '.test_profile\Roaming'
$env:LOCALAPPDATA = Join-Path (Get-Location).Path '.test_profile\Local'
..\Godot_v4.7.2-stable_win64_console.exe --path . --script res://tests/ui_smoke.gd --log-file .\test-results\ui-rendered.log --audio-driver Dummy
```

实际渲染的界面截图保存在 `test-results`，包含卡组拖放、满编自动收纳、四类图鉴及新增路线状态。规则测试涵盖 46 种卡及升级版、两栏卡组存档、旧版存档迁移和 30 局自动对局（每条路线 10 个随机种子）；自动策略的结果仅用于验证流程，不代表玩家真实胜率。

## 卡牌平衡调整

卡牌治疗仅恢复上一轮敌方攻击造成的未恢复伤势，多张共享额度；药水也会扣减该额度，下一轮敌方行动开始时过期。燃血自伤和旧伤不能靠卡牌恢复。棘甲反伤仅持续至下个玩家回合开始，其他反伤能力持续整场。振作、毒素回收提供下回合额外能量；催化翻倍最多新增12层，升级18层。

通用牌具备1、2、3费选择，三条路线均有3费牌。详见[卡牌平衡调整说明](卡牌平衡调整说明.md)及自动生成的卡牌图鉴。
