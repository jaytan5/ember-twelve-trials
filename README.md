# 余烬十二关 · 卡牌游戏 Demo

Godot 4.7.2 项目，12场战斗，第3、6、9、12关为Boss。

## 启动

用 Godot 导入 `project.godot`，或双击 `启动游戏.cmd`。本机引擎位于工程上一级。
入口为 `Game/Scenes/Main.tscn`。

## 界面与冒险流程

默认画布 1600×900（16:9），窗口缩放保持比例；其他比例的屏幕留边显示。

- 开始界面提供「开始新冒险」「继续冒险」「设置」。
- 新冒险先选择路线与难度，再进入关卡地图；有旧存档时确认后才覆盖。
- 继续冒险先确认存档路线，路线与难度锁定；确认后进入地图，保留原卡组、生命和当前战斗/奖励/补给进度。
- 地图分为青苔边境、失落铁城、血砂荒原、余烬王座，每区两场普通战斗和一场 Boss 战。完成战后补给后在地图解锁下一关。
- 右上角设置菜单包含关卡地图、卡组、图鉴、玩法、保存、声音与显示、返回主界面和返回。Esc 打开/关闭菜单。
- 左下为带头像的个人属性面板，中间为可横向滚动的手牌，右侧竖排牌堆按钮，右下结束回合。
- 基础设置支持总音量、音效音量、试听和全屏；音量控制已接入按钮、选敌与出牌音效，偏好独立保存在 user://settings.cfg。

## 当前回合规则

- 初始17张：12张通用牌＋5张路线牌。
- 首回合抽5张，之后每回合保留手牌并抽2张，最多10张；满手牌后停止抽取，牌留在牌库。
- 普通牌使用后进入弃牌堆；抽牌堆空时洗入弃牌堆。能力牌和急救使用后本场移出，下场恢复。
- 每回合默认3能量；厚积薄发可消耗全部当前能量，在下一回合额外获得对应能量。
- 点击目标、点击卡牌，数字1–9、0出牌，左右方向键选敌，空格结束回合。
- 出战卡组5–30张，战斗外可以在出战与备用卡库之间移动卡牌。

完整卡牌、升级效果见 [卡牌与路线说明](卡牌与路线说明.md)，关卡和怪物数值见 [完整设定](游戏完整设定-卡牌与怪物.md)。

## 模块和数据

见 [工程结构说明](Game/ARCHITECTURE.md)。卡牌、怪物、Boss、关卡、遗物和奖励均使用独立 `.tres` Resource。调数值直接编辑对应资源；增加全新机制时扩展效果结算器。

旧 `scripts/` 和 `main.tscn` 作为兼容入口保留，实际实现位于 `Game/`。

## 存档

新版为v5，兼容v1–v4。已删除卡牌迁移为：应急包扎→卸力、振作→厚积薄发、佯攻→识破、未雨绸缪→金钟罩；重复副本与升级保留。旧存档超过10张的手牌移回抽牌堆，不丢失。既有卡组不会被强制换成新初始牌；开始新冒险即可体验17张起始配置。

测试使用工程内 `.test_profile`，不会覆盖玩家存档。

## 验证

在项目目录执行 `powershell -ExecutionPolicy Bypass -File tests/run_checks.ps1`。
添加 `-Rendered` 可运行实际渲染截图检查。日志和截图存于 `test-results/`。
测试覆盖卡牌升级、保留手牌、10张上限、冰冻、金钟罩、X费用、消耗牌、迁移与随机状态，以及三路线自动对局；界面检查覆盖主界面→路线→地图→战斗、锁定路线续玩、地图往返不重置战斗、音量持久化、十张手牌快捷键及窗口比例。自动胜率仅用于回归，不代表玩家胜率。
