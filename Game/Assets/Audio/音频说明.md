# 游戏音频登记

## 开始界面 BGM

- 曲目：The World-Saving Heroic Quest。
- 原始素材：`G:\godot\声音\BGM音乐\The+World-Saving+Heroic+Quest.mp3`，原文件保留。
- 转换副本：`G:\godot\声音\BGM音乐\The+World-Saving+Heroic+Quest.ogg`。
- 游戏内资源：`res://Game/Assets/Audio/BGM/The+World-Saving+Heroic+Quest.ogg`。项目直接引用该资源，打包时无需依赖项目外的声音目录。
- 格式：OGG / Vorbis，44.1 kHz，双声道，质量参数 5，完整时长约 2 分 26 秒。
- 播放：开场标题 `title`、开始界面 `home` 和路线选择 `routes` 自动循环；首次操作揭开菜单时连续播放。进入地图或战斗等冒险界面停止，返回主界面从头播放。循环点为整曲结尾回到 0 秒，未裁剪或改变速度。
- 实现：`Game/Scripts/SaveSystem/AppSettings.gd` 内的 `MenuBGM`（AudioStreamPlayer），设置 `AudioStreamOggVorbis.loop = true`；`Game/Scenes/UI/GameShell.gd` 在 `render()` 中按界面状态启停。播放器保留在设置节点下，界面重绘不会销毁或重复创建播放器。
- 音量：播放器基准音量 -12 dB，经 `Master` 总线输出，受现有设置中的「总音量」控制，可调为 0 静音；「音效音量」只控制按钮等音效。

转换命令（FFmpeg）：

```powershell
ffmpeg -i 'G:\godot\声音\BGM音乐\The+World-Saving+Heroic+Quest.mp3' -map 0:a:0 -c:a libvorbis -q:a 5 'G:\godot\声音\BGM音乐\The+World-Saving+Heroic+Quest.ogg'
```
