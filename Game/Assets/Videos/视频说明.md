# 游戏视频登记

## 开始界面循环背景

- 原始素材：`G:\godot\视频文件\开篇循环背景动画.mp4`，保留原文件。
- 转换副本：`G:\godot\视频文件\开篇循环背景动画.ogv`。
- 游戏内资源：`res://Game/Assets/Videos/MainMenu/开篇循环背景动画.ogv`。直接引用项目内资源，运行和打包无需依赖外部视频目录。
- 编码：OGV 容器 / Theora 视频，质量参数 8，yuv420p，24 帧/秒，完整时长约 10 秒。
- 画面：原片为 1916×1080；左右各补 2 像素黑边，输出 1920×1080，适配项目 16:9 画布，未裁剪或改变速度。
- 静音：转换时通过 `-map 0:v:0 -an -sn -dn` 只保留首条视频流，删除全部音轨、字幕和数据流；游戏内播放器音量另设为 0。
- 播放范围：开场标题 `title` 与开始界面 `home`。自动播放并设置 `VideoStreamPlayer.loop = true`，完整播放到结尾后回到开头；title 揭开菜单时连续播放，离开开始界面停止，返回时从头播放。
- 声音：继续由独立菜单 BGM 播放器提供，沿用「总音量」设置，视频没有声音。
- 界面：视频铺满逻辑画布；title 不加暗色遮罩，仅叠加透明 Logo 和白色开始提示，home 使用轻度暗色遮罩和右侧半透明菜单保证文字可读；播放器不接收鼠标事件，原有按钮与设置功能保留。
- 实现：`Game/Scenes/MainMenu/HomeView.gd` 创建 `HomeVideoBackground/OpeningVideo`；`Game/Scenes/UI/GameShell.gd` 按界面状态调用 `update_background()`，重绘时保留背景播放器，打开设置和重复渲染不会从头播放。

转换命令（FFmpeg）：

```powershell
ffmpeg -i 'G:\godot\视频文件\开篇循环背景动画.mp4' -map 0:v:0 -an -sn -dn -vf 'pad=1920:1080:2:0,setsar=1' -c:v libtheora -q:v 8 -pix_fmt yuv420p -map_metadata -1 'G:\godot\视频文件\开篇循环背景动画.ogv'
```
