# 开始界面 UI 素材

2026-11-04 按用户确认的暖红棕预览制作，使用内置 imagegen 生成透明 PNG。

- `开始游戏.png`：砖红皮革底、细暖金边、奶油色文字及三张卡牌徽饰。
- `继续游戏.png`：红棕皮革底、暖金边、地图和指南针徽饰；游戏内进一步压暗为深栗棕，无存档时显示禁用状态。
- `设置齿轮.png`：暖棕底、黄铜圆边及齿轮图标。

参考为本次确认的开始界面预览。三个素材分别生成，保留原始透明 PNG；`HomeView.gd` 通过 `AtlasTexture` 排除导出留白并保留装饰比例。按钮宽度为 292 个逻辑像素，在 1280×720 默认窗口约为 234 像素，随游戏画布等比缩放。

生成提示词要点：仅重建预览中指定的单个按钮；保留其中文原文、纤细金边、暖红棕配色和对应卡牌/指南针徽饰；正面、独立完整轮廓、真实透明背景、高分辨率；无场景、无其他按钮、无额外文字、无水印。设置素材同样仅重建右上角的暖棕金色圆形齿轮。

交互：鼠标悬停或键盘聚焦时轻微提亮放大，按下时轻微缩小；支持 Tab/方向键聚焦及确认。启动时显示原 Logo 与“按任意键开始游戏”，触发后显示独立菜单，视频和音乐继续播放。
