# 开始界面 UI 素材

## 当前使用版本：圆角立体版（2026-11-05）

用户确认主界面替换示意后，两个主菜单按钮与右上角设置已更换为高精度 3D 风格化卡通的圆角立体版。均采用相机垂直按钮正面的正交视角，使用内部倒角、暖光高光和柔和接触阴影表现体积。

- `圆角立体版/主按钮_红金.png`：红色珐琅正面、暖金倒角，无文字透明底图。
- `圆角立体版/次按钮_古铜棕.png`：同系列轮廓的古铜棕按钮，无文字透明底图。
- `圆角立体版/设置_圆齿轮.png`：深棕圆盘与暖金齿轮，正交视角透明资源。
- 素材由内置 imagegen 分别生成，真实 Alpha 保留自然投影；提示词见本目录 `圆角立体版/生成提示词.json`。原版图片仍保留，当前 `HomeView.gd` 已切换到新目录。

显示：两按钮可视宽约 292 个逻辑像素、高约 76，控制区为 304×90（包含投影边距）；设置控制区继续为 84×84，实际可视主体略小。背景视频、原 Logo 与位置锚点继续沿用。

文字使用独立的方圆体粗体资源 `Game/Assets/Fonts/主菜单按钮粗体.tres`，由引擎绘制暖奶油字、深棕描边与短投影。正文不烘焙进图片，避免缩放后乱码和后续改文案困难。

纹理开启 mipmaps 和透明边缘修正；`AtlasTexture` 只排除导出留白，保留投影的透明衰减边缘。点击遮罩以 Alpha 0.5 生成，阴影和透明圆角不响应点击。保留鼠标悬停、按下、键盘焦点、无存档禁用与点击音效，提亮和缩放幅度减弱，避免过亮金边与跳动。

验收脚本：`tests/test_home_menu_refresh.gd`，只读取现有存档和设置，不写入或删除用户文件；检查实际资源引用、文案、透明角、鼠标、键盘、背景连续播放、禁用样式及 1600×900 / 1280×720 / 1024×768 显示。

## 历史版本：暖红棕铭牌（2026-11-04）

2026-11-04 按用户确认的暖红棕预览制作，使用内置 imagegen 生成透明 PNG。

- `开始游戏.png`：砖红皮革底、细暖金边、奶油色文字及三张卡牌徽饰。
- `继续游戏.png`：红棕皮革底、暖金边、地图和指南针徽饰；游戏内进一步压暗为深栗棕，无存档时显示禁用状态。
- `设置齿轮.png`：暖棕底、黄铜圆边及齿轮图标。

参考为本次确认的开始界面预览。三个素材分别生成，保留原始透明 PNG；`HomeView.gd` 通过 `AtlasTexture` 排除导出留白并保留装饰比例。按钮宽度为 292 个逻辑像素，在 1280×720 默认窗口约为 234 像素，随游戏画布等比缩放。

生成提示词要点：仅重建预览中指定的单个按钮；保留其中文原文、纤细金边、暖红棕配色和对应卡牌/指南针徽饰；正面、独立完整轮廓、真实透明背景、高分辨率；无场景、无其他按钮、无额外文字、无水印。设置素材同样仅重建右上角的暖棕金色圆形齿轮。

交互：鼠标悬停或键盘聚焦时轻微提亮放大，按下时轻微缩小；支持 Tab/方向键聚焦及确认。启动时显示原 Logo 与“按任意键开始游戏”，触发后显示独立菜单，视频和音乐继续播放。
