# 星芒小剑指针

- 用户原图：`星芒小剑-用户原图.png`，来自本次上传的小剑图片。
- 透明成品：`星芒小剑-透明.png`，使用内置 imagegen 工具抠图，保留剑身、星纹、宝石、护手、剑柄与红色飘带。
- 游戏接入：`Game/Scenes/UI/GameCursor.gd` 加载项目内 PNG，缩放为 48×48 像素硬件指针，以剑尖附近的 `(5, 1)` 为点击热点。
- 所有指针形态均使用小剑，鼠标移到按钮、拖动卡牌或等待结算时保持统一外观。
- 显示时由 `GameCursor.gd` 为小剑合成向右下偏移的轻微柔和阴影，保留 48×48 尺寸和原点击热点；原透明 PNG 保持不变。
- 鼠标左键按下时，`CursorClickEffect.gd` 在点击处显示小金色光圈及四点微光，约 0.32 秒淡出。特效位于弹窗上方，不拦截按钮或拖动操作，快速连点最多保留 8 个特效。
- 原图和透明 PNG 均保存在游戏内，不依赖临时附件路径。
- 制作日期：2026-11-04。
- 阴影与点击反馈更新：2026-11-06。
