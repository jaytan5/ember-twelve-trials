# 天赋选择界面定稿 v2

接入日期：2026-11-06。依据 `G:\godot\UI拆分预览\天赋路线_v2` 已确认的美术方案。

## 资源与文字

生产目录内包含 15 张独立 PNG：村庄背景、人物含随身投影、框架与牌匾、三种卡包、底部木托盘、普通难度按钮、含勾选中难度按钮、开始按钮、返回按钮、已选择徽章、三类卡包轮廓光晕。没有把完整组装图作为游戏界面背景。

背景使用已确认的远端上部渐变虚化版本。人物和脚下接触／地面软投影在同一纹理，移动人物节点就会同步移动投影。灯笼、旗帜、牌匾和木架作为结构完整的框架组，保留材质连接及接触阴影。

狂刃轮廓光晕直接复用确认版；蚀毒、铁壁根据各自透明轮廓使用相同算法派生。内部开口向内缩 10 个设计像素，光晕放在卡包之后；外侧柔化半径、金色和强度不变。主体纹理不随光晕变色，也不再使用旧版大幅压暗未选项的效果。

标题、提示、卡包名、难度、返回、开始／继续和已选择都是原生文本。`TalentText.gd` 使用 TextServer 的实际字形轮廓边界校准中心，投影不参与居中计算；独立方圆字体保持字重 700、圆角轴 100，并少量增粗适配引擎渲染。卡包不显示悬停小字提示。

## 布局与交互

`界面布局.json` 保存 1672×941 的设计坐标。界面画布按窗口等比缩放并居中，背景单独铺满；同一张普通／选中贴图可以复用在四个难度上，选中项仍只有一个。

卡包与按钮使用各自 Alpha 生成点击遮罩，透明角不拦截点击。键盘按视觉顺序切换，焦点保留轻微受光反馈，不绘制下方虚线；选中状态由金色光晕、已选择徽章或红色含勾按钮表达。按钮按下仅轻微调整受光，不改变文字居中或引入外凸底座。续玩时沿用存档路线和难度并锁定七个选择项；返回、开始与继续调用原有业务逻辑。

所有新 PNG 均启用 mipmap 并使用线性 mipmap 采样，减少高分辨率材质缩小时的锯齿、噪点与透明边缘闪烁。资源留有阴影和光晕所需透明边距。

## 验证与复现

`tests/test_talent_ui.gd` 验证九个交互入口、透明角点击、唯一选中与标记、键盘、实际字形居中、窗口适配、存档锁定、续玩和返回主页，并可导出实际游戏截图。`test-results/talent-approved-v2.png` 为狂刃＋标准的游戏渲染截图。

使用 `tools/导入天赋选择定稿.ps1` 可从工作区确认版复制原始切图、派生另外两类光晕并生成布局。该导入工具依赖工作区中的 v2 制作记录；游戏运行只依赖本项目目录内资源，不依赖外部预览目录。

旧版素材与脚本保留供回看，新的天赋页不再引用旧版展示板、路线卡、难度图、旧 modules.json 或共享 SelectionOutline 着色器。主页视频、Logo、按钮和设置没有随天赋页一起替换。
