# 《小泥团，出击！》UI 美术方向修订 v1.2

日期：2026-11-05。

> 按钮视角最新修订：用户要求按钮采用垂直俯视。按钮以相机光轴垂直正面的正交视角为准，正面与画面平行，不展示向下伸出的外侧底座。立体感由轮廓以内的倒角、凸面、内槽和材质光影表达；按下表现为内面下陷，外轮廓保持相同。本文早期关于按钮下侧外露 15%–20% 的探索参数不再适用。此修订仅针对按钮，不改变面板、地图与指南针道具的视角。

## 修订结论

用户指出 v1.1 风格过轻，与期望的 Supercell 类游戏 UI 差距较大，也不足以匹配当前高精度 3D 风格化卡通场景。本版收回 v1.1 作为定稿依据的定位，将目标重新明确为：

**高精度 3D 风格化卡通 UI：饱满且夸张的体块、雕塑感的轮廓、明显挤出的底座、清楚的结构遮挡、简化而有层次的材质，以及与角色和场景接近的渲染完成度。**

参考《皇室战争》《部落冲突》的夸张比例、清晰大形与道具感，同时满足本项目场景的高精度要求。红、金、棕、奶油色关系保留，主菜单具体色值继续采用用户上传 v1.0 的材质明暗组。

本版属于美术方向修订稿。概念图展示的是目标渲染质感，未交付实际 3D 模型、独立切图或游戏内实现。

## 1. v1.1 为什么不足

- 主要使用规整圆角、平滑渐变和较浅的底座，组件本身的几何塑形不够有力。
- 框体、标题牌和按钮的层间遮挡较弱，接触处缺少足够的深度线索。
- 图标与装饰的形体完成度低于场景角色，容易在高精度背景前显得单薄。
- 对细金边、克制厚度的反复强调压低了整体体积；仅增加颜色明暗无法解决。
- 米色展示板能说明色彩搭配，但不足以验证它与真实场景的适配。

因此，v1.1 中“底座约 8%–12% 按钮高度”“极窄金边”等参数不再作为约束。本次先确立足够强的形体，再按实际显示尺寸校准。

## 2. 新的形体标准

### 按钮

- 正面是饱满的隆起面，宽倒角形成真实可见的上缘、侧缘和下缘。
- 下侧底座具有明显挤出厚度，默认状态约占按钮总高的 `15%–20%`，作为效果探索起点；实际尺寸下必须仍能辨认。
- 红色正面、金色包边、深红／棕色底座分别形成可读的结构。按下时移动正面并收缩底座露出量。
- 轮廓允许适度夸张和轻微外扩，不机械限定为标准胶囊；转折保持圆润。
- 边框是具有正面、侧面和转角的金属构件；宽度取决于整体结构，不能退化为细线，也不能遮住按钮主体。

### 弹窗框体

- 棕色外壳有明确的结构厚度和轮廓转折，阅读内板嵌入壳体。
- 标题牌、框体、内板之间存在清楚的前后关系；接缝与遮挡位置有紧密接触阴影。
- 可采用少量圆润金属护角或包边，每一处都对应结构支撑，避免无功能纹样堆叠。
- 大形可简化，但近看应有平滑倒角、材质转折和完整的渲染层次。

### 图标与徽章

- 以立体道具的形体思路制作：指南针有外壳、内盘、指针；卡牌有厚度、边框和独立正面。
- 使用简化、略夸张的几何形，缩小后仍能认出功能。
- 与按钮使用一致的光照、材质精度和阴影，不混入平面剪贴画。
- 减少细碎纹样，把精度用在轮廓、倒角、材质和接触处。

## 3. 匹配高精度 3D 风格化卡通画面的标准

| 维度 | 执行要求 |
|---|---|
| 几何观感 | 像经过完整建模和渲染的卡通道具，边缘圆润，厚度与装配关系可读 |
| 材质 | 珐琅有饱满面与宽高光，金属有暖色反射与暗侧面，阅读底板偏哑光 |
| 光照 | 统一暖色左上主光，保留补光层次；反光、接触阴影、投影共同表达体积 |
| 色彩 | 保留现有红金棕体系；不要把红面全部压成棕色，也不要把金属提成荧光黄 |
| 表面细节 | 适度且有目的；高精度通过造型与材质表达，避免用噪点和做旧堆“细节” |
| 字体 | 标题和按钮字厚实，短挤出和深棕描边清楚；正文保持干净，避免长文全部立体化 |
| 背景关系 | 放进当前角色和环境中比较轮廓、材质和细节层级，不能只在纯色板上验收 |

## 4. 保持游戏 UI 的可用性

- 精度和体积增强不意味着界面必须放大；实际按钮仍按原主菜单占屏关系与点击需求布局。
- 长对白、说明和设置列表保留平静阅读区，装饰与高光退到边缘。
- 外壳和徽章不能侵占正文安全区，关闭按钮不能压过主操作。
- 按钮状态优先表现真实下压；减少整张贴图放大缩小对厚度的替代。
- 场景效果稿仅验证单个弹窗的美术方向，不能据此认定所有界面、状态与尺寸已完成适配。

## 5. Godot 落地建议

高精度 3D 观感可用预渲染透明贴图实现，不要求所有 UI 都实时渲染三维模型。

- 底座、可按压正面、图标、真实文本分层制作，按下时单独移动正面。
- 可伸缩框体采用九宫格，保护角部倒角；徽章、护角和固定纹样单独叠放。
- 阴影需要独立控制边距与透明度，避免缩放后出现厚黑边或裁切。
- 正式中文使用引擎字体；概念图中的字不作为最终文字资产。
- 概念阶段的“高模渲染质感”描述不等于已制作模型或生产级 PBR 材质。
